第 11 章 · 没有动作标签：隐动作与世界模型

▶ 打开本章可交互动画

本章回答：机器人示范要靠人遥操作，又贵又少；网上的视频多得是，却没有动作标签。怎么让 VLA 从没有动作的视频里学东西？
讲解日期：2026-11-20 · 上一章：第 10 章 慢想快做 · 下一章：第 12 章 RL 后训练：Recap
对应原文：materials/text/papers/lapa-2410.11758.txt（LAPA）摘要 L26–L45、§3.1–3.2 L215–L256、L118–L124；genie-2402.15391.txt（Genie）L43–L44、L186–L200、L246–L250；univla-2505.06111.txt（UniVLA）L62–L76、L92–L100；unipi-2302.00111.txt（UniPi）L81–L94；gr2-2410.06158.txt（GR-2）L20–L27
本章缩写：LAPA = Latent Action Pretraining（隐 / 动作 / 预训练）；VQ-VAE = Vector-Quantized Variational AutoEncoder（向量 / 量化 / 变分 / 自编码器）；IDM = Inverse Dynamics Model（逆 / 动力学 / 模型）；LAM = Latent Action Model（隐 / 动作 / 模型）；DINOv2 = 自监督视觉特征模型（DINO = self-DIstillation with NO labels：无标签自蒸馏）；UniPi = Universal Policy（通用 / 策略）；GR = Generative Robot（ByteDance 的生成式机器人模型）。全表见 appendix-glossary.md

讲解

第 1 步：问题，视频很多，动作标签很少（2026-11-20）

类比：学做菜。 你可以看几千个做菜视频，但视频里没写"手腕转了 15 度、用了 3 牛的力"。你得自己看出"这里是在翻炒""这里是在倒油"。

LAPA 摘要把问题说得很直接（L26–L32）：现有 VLA 预训练要靠人遥操作采集的动作标签，这严重限制了数据来源和规模；而网上的视频没有机器人动作标签。引言又补了第二个难点：网上视频里的身体、环境和机器人差别很大（L37–L44）。

数据 多不多 有没有动作标签 是不是机器人的身体
遥操作示范（第 2 章） 少，贵 有 是
网上的人类视频 极多 没有 不是

一句话：视频里有"世界怎么变"的知识，缺的是"动作"这一栏。

第 2 步：隐动作，让模型自己给两帧之间起个名字（2026-11-20）

类比：看动画片配字幕。 你不知道角色按了哪个按键，但看前后两帧，你可以说"他往右跳了"。如果只许你用 8 个词来描述（右、右上、上……），你就会只描述最要紧的变化。

做法（Genie L186–L200；LAPA L215–L238）：训练一个"编码器 + 解码器"：

部分 输入 输出 另一个名字
编码器 这一帧 \(x_t\) + 下一帧 \(x_{t+H}\) 一个码 \(z_t\)（隐动作） 逆动力学模型（IDM）：从结果反推动作
解码器 这一帧 \(x_t\) + 码 \(z_t\) 还原下一帧 \(\hat x_{t+H}\) 世界模型：给动作，预测会发生什么

关键是码本很小：用 VQ-VAE 把 \(z_t\) 只能从一个很小的码本里选。Genie 只用 \(\lvert A \rvert = 8\) 个码（L192–L195）。解码器只拿到"这一帧 + 码"，所以码必须记下两帧之间最要紧的变化，否则还原不出下一帧（L196–L199）。训练只靠"还原得像不像"，全程不需要任何动作标签。

读法：\(z_t = \mathrm{Enc}(x_t, x_{t+H})\)，"z 下标 t 等于编码器括号 x t、x t 加 H"；\(\hat x_{t+H} = \mathrm{Dec}(x_t, z_t)\)，"x hat"是还原出来的下一帧。

数字例子（动画里同一个玩具设定，数是编的）：画面简化成一个小球的位置。这一帧在 (0, 0)，下一帧在 (1.6, −2.0)。编码器算出变化 (1.6, −2.0)，在 8 个方向里最接近"↘"，于是选码 z7。解码器只知道"↘、走一步"，还原到大约 (1.1, −1.1)，有误差，但方向对了。

LAPA 的一个发现（L1026–L1028，附录）：训练好以后，编码器就是一个逆动力学模型，解码器就是一个世界模型。

一句话：隐动作 = 模型自己从前后两帧里总结出来的"动作词"，码本小，逼它只记最要紧的变化。

第 3 步：把隐动作用进 VLA，LAPA 三段式（2026-11-20）

类比：先学"翻炒、倒油"这些说法，再学自己手腕该怎么动。

LAPA 分三段（摘要 L28–L33，§3.2 L249–L256）：

段 做什么 数据
1. 学码 训练第 2 步的编码器 + 解码器 只要视频
2. 隐动作预训练 用编码器把所有视频帧标上码；让 VLM 看画面 + 指令，预测码（像念词，第 6 章） 视频 + 文字说明，不要动作
3. 微调 用少量真实机器人数据，学"码 → 真实关节动作" 少量遥操作数据

第 2 段给 VLM 加了一个单独的"隐动作头"（一层 MLP，输出码本大小那么多类，L252–L253）。

效果（L118–L124）：比用真实动作标签训练的最强 VLA 还高 6.22%，预训练效率高 30 倍以上。只用人类做事的视频训练，也有正面迁移。

UniVLA 的改进：只记跟任务有关的变化（L62–L76、L92–L100）

只看"还原得像不像"有个问题：画面里和任务无关的变化也会被记进码，比如别人走过、镜头晃动（L95–L97）。UniVLA 的办法： - 不在像素上算，而在 DINOv2 特征上算：这种特征更关注物体，对镜头晃动不敏感； - 用语言指令帮忙，把"跟任务有关的动作"和"无关的变化"分开。

结果：比 OpenVLA 强，预训练算力不到它的 1/20，下游数据只要 1/10（L74–L75）。

一句话：先用视频学"动作词"，再用少量机器人数据学"词 → 关节"。

第 4 步：另一条路，先想象视频，再反推动作（2026-11-20）

类比：先在脑子里过一遍"做完是什么样子"，再照着去做。

模型 做法 原文
UniPi 文字 → 生成一段未来视频（视频扩散模型）→ 逆动力学模型从生成的视频里反推动作 UniPi L84–L91
GR-1 / GR-2 先在大量视频上做视频预测预训练（GR-2 用了 3800 万段、500 多亿 token），再用机器人轨迹同时学"预测视频 + 预测动作" GR-2 L20–L27

UniPi 的说法：因为任务的文字描述往往和动作高度相关，按文字生成视频，会自然地把注意力放在和动作有关的部分（L91–L93）。

两条路对比

隐动作（LAPA / UniVLA / Genie） 想象视频（UniPi / GR-2）
中间表示 一个小码 一整段未来画面
推理成本 低（念几个词） 高（要生成视频）
能看懂吗 码要再解读 视频人能直接看

两条路都在第 11 章的问题上给出答案：用视频学"世界会怎么变"，只把"怎么用这具身体做到"留给少量机器人数据。这也是"世界模型 / WAM"路线的起点，详见面试资料 05 世界模型与 WAM。

一句话：要么学一个动作的"代号"，要么直接想象出未来画面；两种都把视频里的知识搬进机器人。

数学原理

  • 向量量化（VQ）：\(z = \arg\min_k \lVert e - c_k \rVert\)，在码本 \(\{c_1, \dots, c_K\}\) 里找离 \(e\) 最近的那个；梯度用"直通"或 NSVQ 之类的技巧绕过 arg min。
  • 信息瓶颈：码本越小，码能携带的信息越少（8 个码最多 3 比特），模型被迫只编码最重要的变化。
  • 逆动力学 vs 正向动力学：逆：\((x_t, x_{t+1}) \to a_t\)；正：\((x_t, a_t) \to x_{t+1}\)。隐动作模型同时训练两者。

公式清单

公式 意思
\(z_t = \mathrm{VQ}(\mathrm{Enc}(x_t, x_{t+H}))\) 编码器看两帧，选一个码（隐动作）
\(\hat x_{t+H} = \mathrm{Dec}(x_t, z_t)\) 解码器用这一帧 + 码还原下一帧
\(L = \lVert \hat x_{t+H} - x_{t+H} \rVert^2 + \text{VQ 项}\) 只靠还原误差训练，不需要动作标签
\(p_\theta(z_t \mid x_t, \ell)\) LAPA 第 2 段：VLM 看画面 + 指令预测码
